# 🌐 LibraSphere — Управление библиотекой в двух измерениях

> **Два интерфейса. Одна логика. Одна база. Бесконечные возможности.**

**LibraSphere** — это элегантное решение для управления библиотекой книг, сочетающее в себе **графический интерфейс Windows Forms** и **консольное приложение**, работающие через **общую бизнес-логику** с **PostgreSQL**.  
Идеально подходит для обучения, портфолио или как основа для расширения.

---

## 🚀 Возможности

### 🖥 Windows Forms App
- ✅ Добавление, редактирование, удаление книг
- ✅ Управление категориями
- ✅ Поиск по году и категории
- ✅ Таблицы, формы, ComboBox, NumericUpDown
- ✅ Отдельная форма редактирования с предзаполнением полей

### ⌨️ Консольное приложение
- ✅ Работа с книгами и категориями через командную строку
- ✅ Вывод списков, поиск по ID, году, категории
- ✅ Идеально для автоматизации и тестирования

### 🧠 Общая логика (LibraSphere.Logic)
- ✅ Чистая архитектура — разделение UI и бизнес-логики
- ✅ Подключение к PostgreSQL через Npgsql
- ✅ Полная поддержка CRUD-операций

---

## 🛠 Технологии

- **Язык**: C#
- **Платформа**: .NET 9
- **Интерфейсы**: Windows Forms, Console App
- **База данных**: PostgreSQL
- **Драйвер**: Npgsql
- **Архитектура**: Многослойная (UI / Logic / Data)
